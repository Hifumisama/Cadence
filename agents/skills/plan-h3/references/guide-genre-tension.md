# Genre "tension" — a build-up or a tipping point

1. **The build-up plays out over the plan's duration**: cuts tighten (from 3 s to 1.5 s) and the frame moves closer or tilts as tension climbs.
2. **The change is a visible, dated gesture.** Light darkening, a sky clouding over, a sound settling in: have an event in a precise shot carry it, not a state described from the start.
3. **A tipping point is set up.** The first shot keeps the scene's mood state (or the neighbouring plan's, see `plansVoisins`); the first sign of change appears next; the break comes in the last third. The previous neighbouring plan has already placed the sign if needed.
4. **Sound precedes image**: a rising bass, a settling silence, before the image changes.
5. **Do not resolve** if the next plan continues: end on the high point.
